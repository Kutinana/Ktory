本節では、Ktory における単一ファイルでの多言語記述の実現方法について解説します。

## 同一ファイルの多言語

`@defaultLang` は本 Ktory スクリプトで既定で使用する言語を宣言します。これは必須の宣言ではなく、空欄のままや未宣言の場合でも Ktory は正常に動作します。この場合、Ktory は言語を独自に推測することはありません。スクリプトやゲームで単一の言語のみを使用することが確実である場合は、`@defaultLang` の宣言を省略できます。そうでない場合、後々の多言語ローカライズで不便が生じる可能性があります。

`@[locale]` は特定のテキストの言語を明示的に宣言します。これによって Ktory の既定言語が変わることはありません。ただし、スクリプト内で `@[locale]` を使って任意のテキストの言語を宣言した場合、`@defaultLang` の宣言が必須となります。このとき、`@[locale]` の注釈がない他のテキストは、自動的に `@defaultLang` の言語として扱われます。

現在、`@[locale]` 宣言はセリフと選択肢ラベルをサポートしています。

```ktory
@defaultLang: ja

アリス:
  @zh: 你好，旅行者。
  @en: Hello, traveler.
  @ja: こんにちは、旅人さん。
  .expression(smile)

#choice
  * [@zh: "继续"]
    [@en: "Continue"]
    [@ja: "続ける"]
    アリス: 私たち、行こう。
```

## キャラクター名と別名

劇本内ではキャラクターの名前が高頻度で登場するため、Ktory はキャラクター名およびその訳名の定義に特化した構文を用意しています。

`@speaker` 宣言はキャラクター名、訳名、および別名を定義します（大文字・小文字は厳密に区別されます）。ファイル先頭で定義しておくと、Ktory は要求された言語に応じて、定義済みの正しい訳名を自動的に返します。なお、別名は任意項目であり、出力言語としては扱われず、スクリプトからの呼び出し入力としてのみ使用できます。

```ktory
@speaker en="Chtholly" | ja="クトリ" | cn="珂朵莉"

Chtholly:  // ここで Chtholly、クトリ、珂朵莉 のいずれを記述しても、要求言語に応じた正しい訳名が自動的に返されます
  @en: You must leave now.
  @ja: 今すぐ離れて!
  @cn: 快走!
```

別名を定義したい場合は、`@speaker` 宣言の直後に別名とコロン（`:`）を付けるだけです。ただし、`@speaker alice:` のように空でない表示名が一つも存在しない宣言は、行番号を出力して読み込みを停止します。

```ktory
@speaker ktr: en="Chtholly" | ja="クトリ" | cn="珂朵莉"

ktr:……  // 別名を使って呼び出すことができます
```

この構文は、キャラクターが演出時に使用する既定修飾子の定義にも対応しています。


## 出力とフォールバック

Ktory は要求された言語を優先して返します。要求言語の翻訳が存在しない場合は、`defaultLang` の言語テキストの取得を試みます。両方に有効な翻訳が存在しない場合、Ktory はそのノードの既存の訳文順に従って最初の有効な翻訳を選択し、ソースコードの位置情報を含んだ `Warning` を出力します。

`TextPayload.ActualLanguage` は実際の本文の言語を示し、`RequestedLanguage` は要求された言語を保持します。例えば、英語（`en`）が要求され `defaultLang` が `zh` の場合、あるテキストで `en` の翻訳が欠落していると、そのテキストの `ActualLanguage` は `zh` となり、`RequestedLanguage` は依然として `en` のままになります。この際、Ktory が `zh` のテキストを英語としてラベル付けすることはありません。

現在、`ChoiceOption` はローカライズされた `Label`、`RequestedLanguage`、および `ActualLanguage` を提供し、各選択肢ごとに実際の言語を個別に報告します。

`TextPayload.SpeakerActualLanguage` は宣言された話者名の実際の言語を個別に報告します。これは本文と異なる場合があり、未宣言の話者の場合は空（null）になります。

本文、選択肢、および宣言済みの名前はいずれも上記の第三言語フォールバック規則に従い、欠訳のプレースホルダーを合成することはありません。

## 再生中の言語切替

```csharp
player.SetLanguage("en");
```

`SetLanguage(locale, token)` はセッション設定です。キャプチャされたセッションが有効である限り、同一セッションで拍が進んだ後や自然終了した後でも言語を変更できます。古いセッションからの要求は無視されます。

切り替えによって現在のテキスト、話者、またはメニューラベルが更新されますが、演出修飾子の再配信やセッション履歴の消去は行われません。その後、宿主側で表示を更新します。`PresentationController` を使用している場合は、その `RefreshLanguage()` を呼び出して現在の演出タイミングを処理してください。言語切り替えのために余分な `Step()` を呼び出さないでください。

同一ファイルでの管理は独立した執筆や翻訳に適しています。ただし、Ktory は言語ごとに複数の Ktory スクリプトファイルを個別に管理することを妨げるものではありません。
