# 同一ファイルの多言語

`@defaultLang` でファイルの既定言語を指定し、省略時は `zh` になります。`@locale` のない本文は既定言語に属します。セリフ、話者の表示名、選択肢ラベルを一緒に管理できます。

```ktory
@defaultLang: zh
@speaker alice: zh="爱丽丝" | en="Alice" | ja="アリス"

alice:
  @zh: 你好，旅行者。
  @en: Hello, traveler.
  @ja: こんにちは、旅人さん。
  .expression(smile)

#choice
  * [@zh: "继续"]
    [@en: "Continue"]
    [@ja: "続ける"]
    alice: 我们出发吧。
```

## 出力とフォールバック

各文は要求言語を優先し、訳がなければ `defaultLang` に戻ります。両方に有効な訳がない場合、そのノードの既存の訳文順に最初の有効な訳を使い、ソース位置付きの `Warning` を出します。`TextPayload.ActualLanguage` は実際の本文の言語、`RequestedLanguage` は要求言語です。この例で英語を要求しても、選択先の未翻訳の文は `zh` になります。その本文を英語として扱わないでください。

`@speaker` は表示名を検索する、大文字と小文字を区別した別名を定義します。ここでは `alice`、`爱丽丝`、`Alice`、`アリス` が一つの名前定義を指します。未定義の話者は記述どおりに表示されます。現在の宣言は名前と別名のみを提供し、立ち絵や音声を自動で結び付けません。製品目標では、名前と任意の既定表示設定を分けて管理し、関連付けや各文での上書きを可能にします。共通定義やリソースの関連付けの構文は未定です。[設計原則](/ja/01-overview/03-design-principles/)を参照してください。

現在の `ChoiceOption` は翻訳済みの `Label`、`RequestedLanguage`、`ActualLanguage` を持ち、各項目の実際の言語を個別に報告します。表示ラベルは項目の `Id` の代わりにはなりません。`TextPayload.SpeakerActualLanguage` は宣言済みの話者名の実際の言語を個別に報告します。本文と異なる場合があり、未宣言の話者では null です。本文、選択肢、宣言済みの名前はいずれも上記の第三言語へのフォールバックを使い、欠訳の代替文を作りません。`@speaker alice:` のように空でない表示名が一つもない話者宣言は、行番号付きのエラーで読み込みを停止します。この決定から本文や選択肢の空宣言に新しい統一規則を適用することはしません。

## 再生中の切替

```csharp
player.SetLanguage("en");
```

`SetLanguage(locale, token)` はセッション設定です。同じ有効なセッションなら、拍が進んだ後や自然終了後も言語を変更できますが、古いセッションからの要求は無視します。

切替は現在の本文、話者、メニューラベルを更新し、修飾子の再通知や履歴の消去は行いません。その後にホストの表示を更新します。`PresentationController` を使う場合は `RefreshLanguage()` で表示状態を更新し、言語切替のために追加の `Step()` を送らないでください。

同一ファイルの訳文は個人の執筆・翻訳に適した方式です。この段階では自動翻訳、訳文の抽出・取込、別ファイル間の同期を約束しません。
