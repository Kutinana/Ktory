Ktory はテキストで制御フロー、ローカライズ、数値条件、演出意図を組み立てます。本ページは 2026-10-22 の契約です。Main／補助の実装・検証は進行中で、公開済みという意味ではありません。

- Main は一つで、入力と補助の create／stop／await を独占します。節は役割を持たず、各ヘッドは位置、呼び出し、ループ、既定時計を保持します。同じ節を複数実行でき、補助は補助を作らず、選択肢・分岐・タグ全体を消費せず無視します。
- 補助は出力後、at／Core 境界まで進み、文字表示、wait／next、AUTO、読書推定を待ちません。Main 終了は補助を停止し、必要な待機は明示 await で書きます。
- 名前付き時計は全体で一つの宣言位置を持ち、初回作成後は再利用します。匿名は各ヘッドの既定からのみ参照し、置換時に解放します。reset は ID を保持します。at は入口条件で、前の拍を進めません。source はホスト解釈で、再生せず、一時的な値の欠落は待機できます。
- 独立 # は既定で自動、Main のテキスト／空 : は手動です。各ヘッドの現在の文は一つだけで、次の文に入ると表示先にかかわらず前の文を撤去します。空 : も同様です。duration は wait と同時に始まりますが advance を妨げません。
- 表示先はタグ／ホスト設定で選び、名前を UI に自動対応させません。末句は完了通知より先で、終了は強制消去ではありません。旧通知は新しい表示を変更できず、残った表示も旧入力権を持ちません。
- 主言語フォールバック、副言語の一致訳、プレーンテキストを維持します。言語更新は進行、副作用、計時、数値源取得を行わず、終了済み補助の保留表示にも対応します。
- 旧 parallel/lane は明示的移行が必要で、入れ子／反復 join は再構成が必要な場合があります。外部ファイルは明示 URL、形式とエンジン読み込みは延期です。信号、保存、race、pause は別議題です。
- 実装・テスト・配布・Unity 実機検証を区別します。検出できる誤りはコンパイル／検査へ前倒ししますが、将来の外部値まで静的には保証しません。予算とバックグラウンド診断を維持します。
