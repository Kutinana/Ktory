# Ktory とは

**Ktory は、対話を中心に、ホストからの入力で拍ごとに進む物語言語とランタイムです。** 個人作者がセリフ、選択肢、演出を起動する意図、多言語訳を一つの脚本にまとめられます。表現方法はホストが決め、コアは次の物語出力を決めます。

## 脚本のように内容を組み立てる

```ktory
@defaultLang: ja
@speaker alice: ja="アリス" | en="Alice"

alice:
  @ja: 今日の風は、どこかいつもと違うみたい。
  @en: The wind feels different today.
  .expression(pensive)

#choice
  * [出発する]
    alice: 行こう。
  + [周りを見る]
    : 窓の外で落ち葉が渦を巻く。
```

セリフと地の文が拍を作り、修飾子がそこに付随します。`.expression(pensive)` はホストに渡す意図です。立ち絵の生成や画像の検索は行わず、リソースの対応付けが存在することも保証しません。

## 共通のコアと明確な接続境界

`src/Ktory.Core` は共通の C# パーサーと実行系です。`netstandard2.1` を対象とし、外部 NuGet 依存はありません。リポジトリの独立試読・WebAssembly ツールは `net9.0` を使い、Unity の公開処理では共有ソースを `com.ktory.unity` にまとめます。

分岐、呼び出し、ループ、セッション履歴はコアが管理します。表示、リソース、時計、入力、ゲーム状態はホストの責任です。テキスト、文字のない指令、選択肢は論理的な停止位置となり、ホストは `Step()` または `SubmitChoice()` の後に出力を読み取ります。

第 1 段階はビジュアルノベル形式のセリフと軽い分岐を対象とします。独立試読は基本の物語と言語を確認し、実際のリソース、立ち絵、その他の演出はホストで検証します。コアの移植性は、各エンジン用アダプターの提供済みを意味しません。
