锚点形成可执行的拍或选项，而修饰符 `.tag(args)` 为其携带参数。拍负责确定剧情停在哪里，演出效果与执行时长由游戏引擎具体实现。

## 节点与结构

| 书写方式 | 解析结构 | 含义 |
| --- | --- | --- |
| `角色: 台词` | `TextStep` | 有说话人的文本拍 |
| `: 旁白` 或无保留前缀的正文 | `TextStep` | 匿名文本拍，`Speaker` 为空 |
| `#do`，下方无子项 | `DirectiveStep` | 无文本指令拍，仍会停止 |
| `#choice`，下方有缩进的 `*` / `+` 子项 | `ContainerStep` | 选项容器 |

`#` 行由子项结构区分指令与容器；`choice` 不是解析器保留关键字。自定义名称的扩展支持需要核查实际运行时，不能只凭名称就假定业务 Handler 已存在。

```ktory
爱丽丝: 真是不可思议……
  .expression(surprised)
  .next(0.5)

#do .sfx("door")
```

修饰符吸附到所属锚点；分支正文和容器子项依缩进划定。`.tag` 与 `.tag()` 都无参，`.tag(0)` 则明确传递整数零。参数可以按位置或名称传入，例如 `.bgm("main", volume=0.6)`。这些名称不会自动提供音频或立绘实现。

修饰符所在块没有上方锚点时，例如文件首行直接写 `.effect`，解析会报出行号并停止加载；不会静默丢弃，也不会自动附给下一句。命名节和分支边界不会提供另一个块的锚点。

配套表现时序约定以秒为单位：`.next(0.5)` 从文字显示完毕后停留半秒并请求推进；`.skippable(false, 3)` 只限制前三秒的文字快显。核心解析这些声明，宿主或配套表现控制器落实时序。

`.wait(t)` 只规定全文显示后的最低停留时间，不会自动推进。期间点击直接丢弃，到期后须重新点击；省略参数的 `.wait` 使用预估阅读时间。`.next(t)` 在全文显示后计时并请求自动推进，省略参数等于 0 秒。

两者同时计时，书写顺序不影响结果：`.wait(2).next(2)` 与 `.next(2).wait(2)` 都是 2 秒后自动推进；`.wait(2).next(5)` 在第 5 秒自动推进，但第 2 秒起可点击提前继续；`.wait(5).next(2)` 必须等到第 5 秒。`.wait.next` 表示预估阅读停留结束后自动推进。`#AUTO` 或宿主自动播放也可提供自动推进策略，但仍须遵守最低停留。

`.skippable(false[, t])` 锁定期间的点击同样直接丢弃，不在解锁或全文显示后补执行。

## 行内样式

支持 `*斜体*`、`**粗体**`、`~~删除线~~` 和 `[书桌]{desk}`。当前脱糖输出为标签字符串，例如 `<ruby="desk">书桌</ruby>`，并非独立的 Ruby 结构化对象。原生标签也会透传，具体标签能否显示由渲染器决定。

使用反斜杠转义需要按字面显示的保留字符。不要把块级 Markdown 标题、列表或代码围栏当作对白结构。跨 Web 与 Unity 的富文本显示需要分别验证。

## 纯文本片段与区块

用三个或更多 ASCII 单引号包住需要原样显示的内容，可内嵌，也可跨多行：

```ktory
爱丽丝: 我想写'''.wait'''，这里的 **粗体** 仍然生效。 .wait(1)
爱丽丝:
  @zh: '''
    .wait
    // 这也是正文
    <b>**不会变成粗体**</b>
  '''
  @en: Text containing '''.wait'''.
  .next(1)
: ''''这里直接显示 ''' 三个单引号''''
```

围栏内不解析 tag、注释、语言标签、控制流、Markdown、Ruby 或原生富文本，也不处理反斜杠转义。围栏外的修饰符属于整拍；多行区块仍只有一拍，各语言版本可独立选择普通或纯文本写法。

开始和结束围栏必须包含同样数量的单引号，且至少三个；内部其他长度的引号串都是文字，不嵌套解析。选择比内容中连续单引号更长的围栏。只显示 `'''` 时，用四个单引号包成多行区块，避免边界与正文连成一串。中文弯引号始终是文字。

单行片段保留内部空白。开始围栏后直接换行的区块移除首尾排版换行及正文公共缩进，保留相对缩进、内部空行和行尾空格；tab 按两列计算。围栏未闭合会报告开始行／列并停止加载。

接入层读取各语言结果的 `Segments`（如果存在），将 `IsLiteral=true` 的片段按纯文本显示并保留空白；其他片段沿用富文本处理。仅把拼接的 `Content` 再当富文本显示会丢失这层区别。共用 Reader 已支持；其他宿主需落实对应渲染。
