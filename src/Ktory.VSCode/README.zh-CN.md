# Ktory for VS Code

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

`.ktr` 语法高亮与离线预览阅读面板，由 Ktory C# 核心驱动。

## 什么是 Ktory

Ktory 是一套专为对白驱动型游戏设计的创作与集成系统。

访问 [Ktory 官方网站](https://ktory.ink) 了解更多信息。

## 安装与阅读预览

1. 从 VS Code 插件市场安装本扩展。
2. 打开任意 `.ktr` 剧本文件，点击编辑器右上角的 **在侧边打开预览 (Open Preview to the Side)** 图标，或执行命令 **Ktory: Open Preview to the Side**。资源管理器右键菜单同样支持该命令。
3. 点击阅读区域或按下 Space / Enter 推进文本显示。使用选项按钮或数字键选择分支。阅读器同时支持自动播放（AUTO）、快进及重播控制。
4. 在预览工具栏中使用**剧本语言下拉框**即时切换对话显示语言。该列表包含 zh/en/ja 以及剧本中提取的语言标签；缺失的翻译遵循核心的回退（fallback）规则。
5. 修改剧本后，点击 **Reload** 按钮或执行 **Ktory: Reload Preview from Editor**。这将读取编辑器当前缓冲区的最新内容（包含未保存修改）并开启新的预览会话。打字编辑不会静默打断正在运行的预览。RESTART 则用于重新播放当前加载的快照。

扩展的界面语言（工具栏、状态与提示信息）由 VS Code 配置项 `ktory.preview.uiLanguage` 严格控制（支持跟随 VS Code 的 `auto`，以及 `zh-cn`、`en`、`ja`），与工具栏中的剧本对话语言相互独立。

每个预览面板跟随显式打开它的文档。切换编辑器标签页不会静默替换故事内容。关闭面板将释放其运行时；重新打开会启动全新会话。解析错误将显示在面板中，若核心提供了源码位置，还会同步显示在 VS Code 的“问题 (Problems)”列表中。诊断信息对应实际加载的版本，并在文档更改时自动清除。

VSIX 安装包内置了 .NET WebAssembly 运行时、Core 核心、桥接层与 Reader 资源。最终用户无需预装 .NET、Unity、本地 Web 服务器或在线连接，剧本不会被上传到任何外部网络。本扩展主要面向桌面版 VS Code（包含标准的远程扩展宿主 Remote Extension Host）；`vscode.dev` 目前不是已验证的目标平台。

预览会忽略未知的外部选项条件，并跳过未知的表现层指令。它支持基础富文本与注音（Ruby）；编辑器预览中会过滤可执行 HTML、加载外部资源的元素及任意 HTML 属性。预览不保证 Unity 渲染、资源绑定或游戏状态行为的一致性。语法高亮基于 TextMate 语法，并非语义分析器或语言服务器（Language Server）。

## 故障排查

若离线运行时加载失败，请检查 **输出 (Output) → Ktory Preview**，然后关闭并重新打开面板。若安装包缺失运行时文件，请重新构建并安装完整的 VSIX 包。语法高亮功能独立于阅读面板运行。
