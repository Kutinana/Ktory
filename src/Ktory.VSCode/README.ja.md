# Ktory for VS Code

[English](https://github.com/Kutinana/Ktory/blob/main/src/Ktory.VSCode/README.md) | [简体中文](https://github.com/Kutinana/Ktory/blob/main/src/Ktory.VSCode/README.zh-CN.md) | [日本語](https://github.com/Kutinana/Ktory/blob/main/src/Ktory.VSCode/README.ja.md)

`.ktr` 構文ハイライトと、Ktory C# コアを搭載したオフライン読書プレビューパネルです。

## Ktory とは

Ktory は対話主導型ゲームのためのオーサリングおよび統合システムです。

詳細については [Ktory 公式サイト](https://ktory.ink) をご覧ください。

## インストールとプレビュー

1. マーケットプレイスから拡張機能をインストールします。
2. `.ktr` ファイルを開き、エディタ右上の **Open Preview to the Side (プレビューを横に表示)** をクリックするか、コマンド **Ktory: Open Preview to the Side** を実行します。エクスプローラーの右クリックメニューからも実行できます。
3. 読書エリアをクリックするか、Space / Enter キーを押してテキストを進めます。選択肢ボタンまたは数字キーで分岐を選択できます。AUTO（自動再生）、早送り、リスタートなどの既存コントロールもサポートしています。
4. プレビューツールバーの**スクリプト言語ドロップダウン**を使用して、対話の表示言語を即座に切り替えることができます。zh/en/ja および読み込まれたスクリプト内で見つかった言語タグが含まれます。翻訳が存在しない場合はコアのフォールバック規則に従います。
5. 編集後は **Reload** ボタンをクリックするか、**Ktory: Reload Preview from Editor** を実行します。これにより未保存の編集内容を含む最新のエディタバッファが読み込まれ、新しいセッションが開始されます。入力中の文字編集によってプレビューが勝手に再起動することはありません。RESTART は読み込まれたスナップショットを再開します。

拡張機能の UI 言語（ツールバー、ステータス、通知）は、VS Code の `ktory.preview.uiLanguage` 設定（VS Code に合わせる `auto`、`zh-cn`、`en`、`ja` をサポート）によって厳密に制御され、ツールバーのスクリプト言語とは完全に独立しています。

プレビューパネルは明示的に開かれたドキュメントに紐付きます。エディタのタブを切り替えてもストーリーが勝手に置き換わることはありません。パネルを閉じるとランタイムが解放され、再度開くと新しいセッションが始まります。構文エラーはパネル内に表示され、コアからソース位置が提供された場合は VS Code の「問題 (Problems)」リストにも報告されます。診断情報は実際にロードされたバージョンを参照し、ドキュメントの変更時にクリアされます。

VSIX パッケージには .NET WebAssembly ランタイム、Core、ブリッジ、および Reader アセットが含まれています。ユーザーは .NET、Unity、ローカルサーバー、オンライン Reader を個別に用意する必要はありません。スクリプトが外部にアップロードされることもありません。本拡張機能はデスクトップ版 VS Code（通常のリモート拡張ホストを含む）を対象としており、`vscode.dev` は検証済みターゲットではありません。

プレビューは未知の外部選択条件を無視し、未知の演出ハンドラをスキップします。基本的なリッチテキストとルビ（Ruby）をサポートしていますが、エディタプレビュー内では実行可能な HTML、外部リソース読み込み要素、任意の HTML 属性は除去されます。Unity での描画、リソースバインディング、ゲーム状態の動作を保証するものではありません。構文ハイライトは TextMate 文法に基づいており、セマンティック検証や言語サーバー（LSP）ではありません。

## トラブルシューティング

オフラインランタイムの読み込みに失敗した場合は、**出力 (Output) → Ktory Preview** を確認し、パネルを一度閉じてから再度開いてください。パッケージにランタイムファイルが不足している場合は、完全な VSIX を再ビルドして再インストールしてください。構文ハイライト機能はプレビューパネルとは独立して動作します。
